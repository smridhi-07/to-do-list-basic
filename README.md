## ✨ Features

- ✅ Add new tasks easily
- ✏️ Edit existing tasks
- 🗑️ Delete tasks you've completed
- 💾 Tasks are saved automatically (using localStorage)
- 🎨 Clean and simple user interface
- 📱 Works on desktop and mobile browsers

## 🛠️ Technologies Used

- **JavaScript (48.5%)** - App logic and interactivity
- **CSS (33.8%)** - Styling and layout
- **HTML (17.7%)** - Structure and markup

## 🚀 How to Use

1. Open the app in your web browser
2. Type a task in the input field
3. Click "Add" or press Enter to add the task
4. Click "Edit" to modify any task
5. Click "Delete" to remove a completed task
6. Your tasks are saved automatically!
